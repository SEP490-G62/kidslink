# UC-N-008: Cập nhật hồ sơ cá nhân / Update Profile (Nutrition)

## Tiếng Việt
- **Diễn giải:** Nhân viên dinh dưỡng có thể cập nhật thông tin hồ sơ cá nhân như họ tên, ảnh đại diện, số điện thoại, email, địa chỉ, ...
- **Diễn viên chính:** Nhân viên dinh dưỡng
- **Mô tả:**
  - Truy cập chức năng cập nhật hồ sơ.
  - Chỉnh sửa các trường thông tin cá nhân.
  - Lưu thay đổi.
- **Điều kiện tiên quyết:** Đã đăng nhập hệ thống.
- **Kết quả sau cùng:** Thông tin hồ sơ cá nhân được cập nhật thành công.
- **Luồng chính:**
  1. Truy cập chức năng cập nhật hồ sơ.
  2. Hệ thống hiển thị thông tin cá nhân hiện tại.
  3. Chỉnh sửa các trường thông tin cần thiết.
  4. Lưu thay đổi.
  5. Hệ thống xác nhận cập nhật thành công.
- **Luồng thay thế:**
  - Thiếu/không hợp lệ thông tin: hệ thống báo lỗi, yêu cầu nhập lại.
  - Lỗi lưu dữ liệu: hệ thống báo lỗi và giữ nguyên trạng thái.

## English
- **Use Case Name:** Update Profile (Nutrition)
- **Description:** Nutrition staff updates personal profile information such as name, avatar, phone number, email, address, etc.
- **Primary Actor:** Nutrition Staff
- **Details:**
  - Access the update profile function.
  - Edit personal information fields.
  - Save changes.
- **Preconditions:** Logged in.
- **Postconditions:** Personal profile information is updated successfully.
- **Normal Flow:**
  1. Access the update profile function.
  2. System displays current personal information.
  3. Edit necessary fields.
  4. Save changes.
  5. System confirms successful update.
- **Alternative Flows:**
  - Missing/invalid information: System shows error and asks to re-enter.
  - Error saving data: System shows error and keeps the current state.

# UC-N-002: Quản lý món ăn / Manage Dishes

## Tiếng Việt
- **Diễn giải:** Nhân viên dinh dưỡng tạo, sửa, xóa món ăn và thông tin dinh dưỡng.
- **Diễn viên chính:** Nhân viên dinh dưỡng
- **Mô tả:**
  - Quản lý danh mục món ăn (tên món, mô tả, ảnh).
  - Khai báo thành phần, thông tin dinh dưỡng cơ bản và cảnh báo dị ứng/kiêng (nếu có).
- **Điều kiện tiên quyết:** Đã đăng nhập.
- **Kết quả sau cùng:** Danh mục món ăn được cập nhật.
- **Luồng chính:**
  1. Truy cập quản lý món ăn.
  2. Tạo/sửa/xóa món ăn.
  3. Lưu thay đổi.
- **Luồng thay thế:** Thiếu tên món/invalid data: hệ thống báo lỗi.

## English
- **Use Case Name:** Manage Dishes
- **Description:** Nutrition staff manages dishes and basic nutrition info.
- **Details:**
  - Manage dish catalog (name, description, image).
  - Declare ingredients, basic nutrition info, and allergy/avoidance warnings (if any).
- **Primary Actor:** Nutrition Staff
- **Preconditions:** Logged in.
- **Postconditions:** Dish catalog updated.
- **Normal Flow:** Access dishes; create/edit/delete; save.
- **Alternative Flows:** Missing name/invalid data: error.

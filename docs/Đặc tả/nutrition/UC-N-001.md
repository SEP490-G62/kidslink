# UC-N-001: Quản lý thực đơn tuần / Manage Weekly Menu

## Tiếng Việt
- **Diễn giải:** Nhân viên dinh dưỡng tạo, sửa, xóa thực đơn theo tuần cho từng độ tuổi/lớp.
- **Diễn viên chính:** Nhân viên dinh dưỡng
- **Mô tả:**
  - Tạo thực đơn theo ngày/bữa (sáng, trưa, xế) cho từng độ tuổi.
  - Gán món ăn vào từng bữa.
  - Sao chép thực đơn từ tuần trước/tuần mẫu.
  - Chọn phạm vi tuần áp dụng (tuần hiện tại hoặc tuần kế tiếp).
- **Điều kiện tiên quyết:**
  - Đã đăng nhập hệ thống.
- **Kết quả sau cùng:**
  - Thực đơn tuần được tạo/sửa/xóa và áp dụng cho lớp tương ứng.
- **Luồng chính:**
  1. Truy cập chức năng quản lý thực đơn tuần.
  2. Chọn tuần và độ tuổi/lớp.
  3. Thêm/chỉnh sửa/xóa món cho từng bữa.
  4. Lưu thay đổi.
- **Luồng thay thế:**
  - Thiếu dữ liệu món/bữa: hệ thống báo lỗi.
  - Trùng thực đơn: hệ thống cảnh báo và yêu cầu xác nhận.

## English
- **Use Case Name:** Manage Weekly Menu
- **Description:** Nutrition staff creates, edits, deletes weekly menus for each age group/class.
- **Primary Actor:** Nutrition Staff
- **Details:**
  - Create daily meals (breakfast, lunch, snack) per age group.
  - Assign dishes to each meal.
  - Copy menu from previous/template week.
- **Preconditions:** Logged in.
- **Postconditions:** Weekly menu is created/updated/deleted and applied to classes.
- **Normal Flow:**
  1. Access weekly menu management.
  2. Select week and age group/class.
  3. Add/edit/delete dishes per meal.
  4. Select apply scope (current week or next week) if available.
  5. Save changes.
- **Alternative Flows:**
  - Missing meal/dish data: error message.
  - Duplicate menu: warning and confirmation.

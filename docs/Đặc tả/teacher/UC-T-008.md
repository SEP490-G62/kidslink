# UC-T-008: Check-in (Điểm danh vào lớp) / Check-in

## Tiếng Việt
- **Diễn giải:** Giáo viên thực hiện điểm danh check-in cho bản thân khi vào lớp hoặc đầu ngày làm việc.
- **Diễn viên chính:** Giáo viên
- **Mô tả:**
  - Chọn chức năng check-in trên ứng dụng.
  - Xác nhận vị trí, thời gian check-in.
  - Hệ thống ghi nhận thời gian, vị trí check-in.
- **Điều kiện tiên quyết:**
  - Giáo viên đã đăng nhập hệ thống.
- **Kết quả sau cùng:**
  - Thông tin check-in được lưu lại, phục vụ quản lý chấm công.
- **Luồng chính:**
  1. Giáo viên truy cập chức năng check-in.
  2. Hệ thống xác định vị trí, thời gian hiện tại.
  3. Giáo viên xác nhận check-in.
  4. Hệ thống lưu thông tin check-in.
- **Luồng thay thế:**
  - Lỗi xác định vị trí/thời gian: Hệ thống báo lỗi, yêu cầu thử lại.
  - Lỗi lưu dữ liệu: Hệ thống báo lỗi và giữ nguyên trạng thái.

## English
- **Use Case Name:** Check-in
- **Description:** Teacher performs check-in for themselves when entering class or at the start of the workday.
- **Primary Actor:** Teacher
- **Details:**
  - Select check-in function in the app.
  - Confirm location and time.
  - System records check-in time and location.
- **Preconditions:**
  - Teacher is logged in.
- **Postconditions:**
  - Check-in information is saved for attendance management.
- **Normal Flow:**
  1. Teacher accesses the check-in function.
  2. System determines current location and time.
  3. Teacher confirms check-in.
  4. System saves check-in information.
- **Alternative Flows:**
  - Error determining location/time: System shows error, asks to retry.
  - Error saving data: System shows error and keeps the current state.

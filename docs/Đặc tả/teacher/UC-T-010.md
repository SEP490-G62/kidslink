# UC-T-010: Cập nhật hồ sơ cá nhân / Update Profile

## Tiếng Việt
- **Diễn giải:** Giáo viên có thể cập nhật thông tin hồ sơ cá nhân như họ tên, ảnh đại diện, số điện thoại, email, địa chỉ, ...
- **Diễn viên chính:** Giáo viên
- **Mô tả:**
  - Truy cập chức năng cập nhật hồ sơ.
  - Chỉnh sửa các trường thông tin cá nhân.
  - Lưu thay đổi.
- **Điều kiện tiên quyết:**
  - Giáo viên đã đăng nhập hệ thống.
- **Kết quả sau cùng:**
  - Thông tin hồ sơ cá nhân được cập nhật thành công.
- **Luồng chính:**
  1. Giáo viên truy cập chức năng cập nhật hồ sơ.
  2. Hệ thống hiển thị thông tin cá nhân hiện tại.
  3. Giáo viên chỉnh sửa các trường thông tin cần thiết.
  4. Giáo viên lưu thay đổi.
  5. Hệ thống xác nhận cập nhật thành công.
- **Luồng thay thế:**
  - Lỗi nhập thiếu/thông tin không hợp lệ: Hệ thống báo lỗi, yêu cầu nhập lại.
  - Lỗi lưu dữ liệu: Hệ thống báo lỗi và giữ nguyên trạng thái.

## English
- **Use Case Name:** Update Profile
- **Description:** Teacher can update their personal profile information such as name, avatar, phone number, email, address, etc.
- **Primary Actor:** Teacher
- **Details:**
  - Access the update profile function.
  - Edit personal information fields.
  - Save changes.
- **Preconditions:**
  - Teacher is logged in.
- **Postconditions:**
  - Personal profile information is updated successfully.
- **Normal Flow:**
  1. Teacher accesses the update profile function.
  2. System displays current personal information.
  3. Teacher edits necessary fields.
  4. Teacher saves changes.
  5. System confirms successful update.
- **Alternative Flows:**
  - Missing/invalid information: System shows error, asks to re-enter.
  - Error saving data: System shows error and keeps the current state.

# UC-T-009: Check-out (Điểm danh ra về) / Check-out

## Tiếng Việt
- **Diễn giải:** Giáo viên thực hiện điểm danh check-out cho bản thân khi ra về hoặc kết thúc ngày làm việc.
- **Diễn viên chính:** Giáo viên
- **Mô tả:**
  - Chọn chức năng check-out trên ứng dụng.
  - Xác nhận vị trí, thời gian check-out.
  - Hệ thống ghi nhận thời gian, vị trí check-out.
- **Điều kiện tiên quyết:**
  - Giáo viên đã đăng nhập hệ thống.
- **Kết quả sau cùng:**
  - Thông tin check-out được lưu lại, phục vụ quản lý chấm công.
- **Luồng chính:**
  1. Giáo viên truy cập chức năng check-out.
  2. Hệ thống xác định vị trí, thời gian hiện tại.
  3. Giáo viên xác nhận check-out.
  4. Hệ thống lưu thông tin check-out.
- **Luồng thay thế:**
  - Lỗi xác định vị trí/thời gian: Hệ thống báo lỗi, yêu cầu thử lại.
  - Lỗi lưu dữ liệu: Hệ thống báo lỗi và giữ nguyên trạng thái.

## English
- **Use Case Name:** Check-out
- **Description:** Teacher performs check-out for themselves when leaving class or at the end of the workday.
- **Primary Actor:** Teacher
- **Details:**
  - Select check-out function in the app.
  - Confirm location and time.
  - System records check-out time and location.
- **Preconditions:**
  - Teacher is logged in.
- **Postconditions:**
  - Check-out information is saved for attendance management.
- **Normal Flow:**
  1. Teacher accesses the check-out function.
  2. System determines current location and time.
  3. Teacher confirms check-out.
  4. System saves check-out information.
- **Alternative Flows:**
  - Error determining location/time: System shows error, asks to retry.
  - Error saving data: System shows error and keeps the current state.

# Danh sách Use Case cho Teacher (theo menu giao diện)


1. UC-T-001: Xem, tạo, bình luận, thích bài đăng (bảng tin/trang chủ) / View, Create, Comment, Like Posts (Newsfeed/Homepage)
2. UC-T-002: Quản lý lớp học, xem danh sách học sinh / Manage Class and View Student List
3. UC-T-003: Ghi nhận điểm danh học sinh / Take Student Attendance
4. UC-T-004: Ghi nhận và gửi báo cáo ngày cho học sinh / Record and Send Daily Student Reports
5. UC-T-005: Xem thời khóa biểu/lịch dạy / View Class Schedule/Teaching Timetable
6. UC-T-006: Chat với phụ huynh / Chat with Parents
7. UC-T-007: Xem và xử lý đơn xin phép của phụ huynh / View and Process Leave Requests from Parents
8. UC-T-008: Check-in (Điểm danh vào lớp) / Check-in
9. UC-T-009: Check-out (Điểm danh ra về) / Check-out
10. UC-T-010: Cập nhật hồ sơ cá nhân / Update Profile

Mỗi use case phức tạp sẽ được đặc tả chi tiết trong thư mục tương ứng.
Nếu bạn muốn đặc tả chi tiết cho use case nào, hãy yêu cầu!

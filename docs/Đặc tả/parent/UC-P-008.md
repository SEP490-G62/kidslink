# UC-P-008: Tạo đơn khiếu nại/góp ý

## Tiếng Việt
- **Diễn giải:** Phụ huynh có thể tạo và gửi đơn khiếu nại hoặc góp ý tới nhà trường hoặc giáo viên.
- **Diễn viên chính:** Phụ huynh
- **Diễn viên phụ:** Hệ thống, giáo viên, nhà trường
- **Mô tả:**
  - Chọn loại đơn (khiếu nại hoặc góp ý).
  - Nhập nội dung, chọn đối tượng nhận (giáo viên hoặc nhà trường).
  - Gửi đơn và theo dõi trạng thái xử lý.
- **Điều kiện tiên quyết:**
  - Phụ huynh đã đăng nhập hệ thống.
- **Kết quả sau cùng:**
  - Đơn được gửi và cập nhật trạng thái xử lý.
- **Luồng chính:**
  1. Phụ huynh truy cập mục "Tạo đơn khiếu nại/góp ý".
  2. Hệ thống hiển thị form tạo đơn.
  3. Phụ huynh nhập nội dung, chọn đối tượng nhận và gửi đơn.
  4. Hệ thống xác nhận gửi thành công và cập nhật trạng thái đơn.
- **Luồng thay thế:**
  - Lỗi gửi đơn: Hệ thống báo lỗi và giữ nguyên trạng thái.

## English
- **Use Case Name:** Create complaint/feedback request
- **Description:** Parent can create and send complaints or feedback to the school or teacher.
- **Primary Actor:** Parent
- **Secondary Actors:** System, Teacher, School
- **Details:**
  - Select type (complaint or feedback).
  - Enter content, select recipient (teacher or school).
  - Submit and track processing status.
- **Preconditions:**
  - Parent is logged in.
- **Postconditions:**
  - The request is sent and processing status is updated.
- **Normal Flow:**
  1. Parent accesses the "Create Complaint/Feedback" section.
  2. System displays the form to create a request.
  3. Parent enters content, selects recipient, and submits.
  4. System confirms successful submission and updates status.
- **Alternative Flows:**
  - Error sending request: System shows error and keeps the current state.

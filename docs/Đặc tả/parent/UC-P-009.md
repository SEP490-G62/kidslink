# UC-P-009: Chat với giáo viên

## Tiếng Việt
- **Diễn giải:** Phụ huynh có thể gửi và nhận tin nhắn với giáo viên của con.
- **Diễn viên chính:** Phụ huynh
- **Diễn viên phụ:** Hệ thống, giáo viên
- **Mô tả:**
  - Xem danh sách giáo viên của con.
  - Gửi, nhận tin nhắn với từng giáo viên.
  - Xem lịch sử trò chuyện.
- **Điều kiện tiên quyết:**
  - Phụ huynh đã đăng nhập hệ thống.
- **Kết quả sau cùng:**
  - Tin nhắn được gửi/nhận thành công, lịch sử trò chuyện được lưu trữ.
- **Luồng chính:**
  1. Phụ huynh truy cập mục "Nhắn tin với giáo viên".
  2. Hệ thống hiển thị danh sách giáo viên của con.
  3. Phụ huynh chọn giáo viên để trò chuyện.
  4. Phụ huynh gửi/nhận tin nhắn với giáo viên.
  5. Hệ thống cập nhật lịch sử trò chuyện.
- **Luồng thay thế:**
  - Lỗi gửi/nhận tin nhắn: Hệ thống báo lỗi và giữ nguyên trạng thái.

## English
- **Use Case Name:** Chat with teachers
- **Description:** Parent can send and receive messages with their child's teachers.
- **Primary Actor:** Parent
- **Secondary Actors:** System, Teacher
- **Details:**
  - View list of child's teachers.
  - Send and receive messages with each teacher.
  - View chat history.
- **Preconditions:**
  - Parent is logged in.
- **Postconditions:**
  - Messages are sent/received successfully, chat history is stored.
- **Normal Flow:**
  1. Parent accesses the "Message with Teacher" section.
  2. System displays the list of child's teachers.
  3. Parent selects a teacher to chat with.
  4. Parent sends/receives messages with the teacher.
  5. System updates the chat history.
- **Alternative Flows:**
  - Error sending/receiving messages: System shows error and keeps the current state.

# UC-P-007: Quản lý người đón

## Tiếng Việt
- **Diễn giải:** Phụ huynh có thể thêm, sửa, xóa và xem danh sách người được phép đón con.
- **Diễn viên chính:** Phụ huynh
- **Diễn viên phụ:** Hệ thống
- **Mô tả:**
  - Xem danh sách người đón đã đăng ký cho con.
  - Thêm mới người đón (họ tên, quan hệ, số điện thoại, ảnh, giấy tờ tuỳ thân).
  - Sửa hoặc xóa thông tin người đón.
- **Điều kiện tiên quyết:**
  - Phụ huynh đã đăng nhập hệ thống.
- **Kết quả sau cùng:**
  - Danh sách người đón được cập nhật chính xác.
- **Luồng chính:**
  1. Phụ huynh truy cập mục "Quản lý người đón".
  2. Hệ thống hiển thị danh sách người đón hiện tại.
  3. Phụ huynh thêm mới, sửa hoặc xóa người đón.
  4. Hệ thống cập nhật và hiển thị thay đổi.
- **Luồng thay thế:**
  - Lỗi khi thêm/sửa/xóa: Hệ thống báo lỗi và giữ nguyên trạng thái.

## English
- **Use Case Name:** Manage pickup persons
- **Description:** Parent can add, edit, delete, and view the list of authorized pickup persons for their child.
- **Primary Actor:** Parent
- **Secondary Actor:** System
- **Details:**
  - View the list of registered pickup persons.
  - Add new pickup person (name, relationship, phone, photo, ID document).
  - Edit or delete pickup person information.
- **Preconditions:**
  - Parent is logged in.
- **Postconditions:**
  - Pickup person list is updated accurately.
- **Normal Flow:**
  1. Parent accesses the "Pickup Management" section.
  2. System displays the current list of pickup persons.
  3. Parent adds, edits, or deletes pickup persons.
  4. System updates and displays the changes.
- **Alternative Flows:**
  - Error when adding/editing/deleting: System shows error and keeps the current state.

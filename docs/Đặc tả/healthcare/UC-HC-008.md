# UC-HC-008: Cập nhật hồ sơ sức khỏe / Update Health Records

## Tiếng Việt
- **Diễn giải:** Nhân viên y tế cập nhật/bổ sung bản ghi sức khỏe (chỉ số, triệu chứng, ghi chú) cho học sinh.
- **Diễn viên chính:** Nhân viên y tế
- **Diễn viên phụ:** Hệ thống
- **Mô tả:** Tạo mới/chỉnh sửa bản ghi sức khỏe theo ngày; đính kèm thông tin cần thiết.
- **Điều kiện tiên quyết:** Đã đăng nhập.
- **Kết quả sau cùng:** Bản ghi sức khỏe được cập nhật/lưu mới thành công.
- **Luồng chính:**
  1. Truy cập mục "Hồ sơ sức khỏe".
  2. Chọn học sinh.
  3. Tạo mới hoặc chỉnh sửa bản ghi (chỉ số, triệu chứng, ghi chú).
  4. Lưu thay đổi.
- **Luồng thay thế:** Thiếu dữ liệu/không hợp lệ: hệ thống báo lỗi.

## English
- **Use Case Name:** Update Health Records
- **Description:** Healthcare staff updates/adds health records (indicators, symptoms, notes) for students.
- **Primary Actor:** Healthcare Staff
- **Secondary Actors:** System
- **Preconditions:** Logged in.
- **Postconditions:** Health record is created/updated successfully.
- **Normal Flow:** Access health records → select student → create/edit record → save.
- **Alternative Flows:** Missing/invalid data: system shows error.
